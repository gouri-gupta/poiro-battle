## Local Setup

### Prerequisites
- Node.js v18+
- MongoDB Atlas account (free tier works)

### 1. Clone the repository
```bash
git clone https://github.com/yourusername/poiro-battle.git
cd poiro-battle
```

### 2. Setup the server
```bash
cd server
npm install
```
